# Insight Invest

Sistema de apoio à decisão para análise de investimentos no mercado financeiro brasileiro, desenvolvido como projeto de Trabalho de Conclusão de Curso (TCC II) do curso de Ciência de Dados para Negócios da Universidade Federal da Paraíba (UFPB).

## Descrição

O Insight Invest tem como objetivo auxiliar o investidor na análise e seleção de ativos financeiros por meio da integração de dados fundamentalistas, estatísticos e macroeconômicos.

O sistema reúne diferentes fontes de dados e aplica indicadores, métodos de análise e modelos de seleção de carteiras para fornecer informações que apoiem o processo de tomada de decisão.

O sistema **não realiza recomendações automáticas de investimento**, mas apresenta informações e análises que podem auxiliar o usuário na avaliação das alternativas disponíveis.

## Principais funcionalidades

- Extração e integração de dados do mercado financeiro;
- Análise fundamentalista dos ativos;
- Cálculo de indicadores microeconômicos;
- Análise de indicadores macroeconômicos;
- Cálculo de scores para avaliação dos ativos;
- Rankings de ativos;
- Análise de risco e retorno;
- Classificação de perfil do investidor;
- Seleção e otimização de carteiras;
- Visualização dos resultados por meio de uma aplicação web.
